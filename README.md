# My Favorite Movie: The Avengers

Welcome to my project repository! Here is a little bit about my favorite movie.

## About the Movie
* **Genre:** Superhero / Action / Sci-Fi
* **Setting:** Earth (New York City) and the Marvel Cinematic Universe
* **Main Premise:** Earth's mightiest heroes must come together and learn to fight as a team to stop Loki and his alien army from subjugating Earth.

> "If we can't protect the Earth, you can be damn well sure we'll avenge it." — Tony Stark

### Main Characters
1. Tony Stark (Iron Man)
2. Steve Rogers (Captain America)
3. Thor Odinson
4. Bruce Banner (The Hulk)
